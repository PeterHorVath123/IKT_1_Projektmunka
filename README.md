# Brainstroming 
## A "megrendelés"
- A veresegyházi egyházlözösség megkért hogy egy mondernizált weboldalt készítsek az ő közösségük számára
- [Versegyház Szentlélek templom](https://veresegyhaz.vaciegyhazmegye.hu/)
### A weboldal tartala 
1. Kezdőlap
1. Történetünk
2. Miserend
3. Kávézó(& közösségeink)
4. Napi imák(napi igevers)


## Az ötlet 
1. Valami ami Istenhez és Jézushoz fűződik
2. Megkérdeztem a claudot hogy segítsen
3. Kiválasztottam hogy egy templomról csinálok

- A claude ajánlott jól kinéző weboldalakat és talátam egy elavult templom weboldalt
- [Jól kinéző templom weboldal ahonnan az inspirációt veszem](https://www.churchome.org/)
- [Elavult templom weboldal](https://www.szfvar.katolikus.hu/hirek)
